# Tiempos Text Typeface

Font files and `@font-face` declarations for **Tiempos Text**, the *expressive* typeface
in the Cadence Design System.

Expressive type is used for brand and editorial surfaces — marketing headlines, hero
sections, long-form article, handbook and lexicon bodies, and quotes. Its app-chrome
counterpart is [`typeface-favorit`](../typeface-favorit/).

A plain CSS package: no build step, no dependencies. Consumers import `index.css`.

Backs `--cds-typography-font-family-expressive-body` and `-expressive-headline`.
