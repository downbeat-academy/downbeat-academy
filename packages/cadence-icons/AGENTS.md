# AGENTS.md — `packages/cadence-icons`

79 icons, generated from SVG source into React components with SVGR. Consumed by
`cadence-core`, `www`, `auth`, and `cadence-links`.

Repo-wide rules live in [`../../AGENTS.md`](../../AGENTS.md).

## The rule that matters most

**`src/components/` is generated output. Never edit it by hand.** Edit the SVG in
`src/assets/` and re-run generation — anything else is overwritten on the next build.

## Commands

```bash
pnpm icons:build                          # clean && svgr — REGENERATES components
pnpm --filter cadence-icons build         # tsc --noEmit && vite build → dist/
pnpm --filter cadence-icons dev           # vite dev server: a browsable icon gallery
pnpm --filter cadence-icons typecheck
pnpm --filter cadence-icons test          # vitest run — the accessibility-defaults suite
```

Note the two-step naming: `icons:build` regenerates components from SVGs;
`build` compiles the package. Adding an icon needs **both**, in that order.

## Layout

```
src/
├── assets/         *.svg — THE SOURCE. 79 files.
├── components/     *.tsx — GENERATED by SVGR. Do not edit.
├── index.ts        barrel
├── __test__/       the accessibility-defaults suite — excluded from tsconfig
├── App.tsx         dev-only icon browser
└── main.tsx        dev-only entry
scripts/ensure-icons.js   prebuild guard — fails the build if generation hasn't run
.svgrrc.json              SVGR config
dist/                     vite output: cadence-icons.{es,umd}.js + index.d.ts
```

## Adding an icon

1. Drop the optimized SVG into `src/assets/`. Name it kebab-case — SVGR converts it to
   PascalCase (`chevron-down.svg` → `ChevronDown`).
2. `pnpm icons:build` — regenerates every component from every asset.
3. `pnpm --filter cadence-icons build` — compiles to `dist/`.
4. `pnpm build:packages` so `cadence-core` and the apps pick it up.
5. Add a changeset.

Consumed as named imports:

```ts
import { ChevronDown } from 'cadence-icons'
```

## Gotchas

- **`pnpm icons:build` runs `clean` first**, deleting all of `src/components/`. Any
  hand-edit there is lost. That is by design.
- **Icons are `aria-hidden` unless named.** An icon with no `title`, `aria-label` or
  `aria-labelledby` renders with `aria-hidden="true"` and **no** `role`; a named one keeps
  `role="img"`. This is the safe default, because decorative is the common case: a
  nameless `role="img"` trips axe's `svg-img-alt`, and makes an icon-only button nameless
  too. That single root cause produced six shipped defects across four PRs. An explicit
  `aria-hidden` from the caller still wins — `{...props}` is spread after the defaults.
  The logic lives in `svgProps` in `.svgrrc.json` and is pinned by
  `src/__test__/icon-accessibility.test.tsx`. **Do not query an untitled icon with
  `getByRole('img', { hidden: true })`** — it has no role to match.
- `dist/` and `src/components/` are both build artefacts. Only `src/assets/` is source.
- The only runtime dependency is `classnames`; React is a peer.
