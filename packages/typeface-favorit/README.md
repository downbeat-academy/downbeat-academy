# Favorit Typeface

Font files and `@font-face` declarations for **ABC Favorit**, the *productive* typeface in
the Cadence Design System.

Productive type is used for app chrome — dashboards, forms, buttons, tables, navigation,
admin surfaces, and microcopy. Its editorial counterpart is
[`typeface-tiempos-text`](../typeface-tiempos-text/).

A plain CSS package: no build step, no dependencies. Consumers import `index.css`.

Backs `--cds-typography-font-family-productive-body` and `-productive-headline`.
